회화 연습 (영어/일본어) - 설치와 사용법
==========================================

[설치]
1. 받은 zip 파일을 "모두 압축 풀기" 합니다. (zip 안에서 바로 실행하면 안 됩니다)
   - 폴더 이름이 너무 길면 안 됩니다. 예: C:\회화 연습  또는  바탕화면\회화 연습
   - 한글이나 띄어쓰기가 들어가도 괜찮습니다.
2. 풀린 폴더의 설치.bat 을 더블클릭합니다.
3. 검은 창에서 단계별(1/10 ~ 10/10)로 자동 설치됩니다.
   - 인터넷이 필요합니다. 약 12 GB를 내려받고 20~60분 걸립니다 (인터넷 속도에 따라).
   - 디스크 여유 공간이 20 GB 이상 필요합니다.
   - 중간에 창을 닫거나 인터넷이 끊겨도 설치.bat 을 다시 실행하면 이어서 합니다.
4. 마지막에 "바탕화면에 바로가기를 만들까요? (Y/N)" 가 나옵니다. Y 를 누르면 바로가기가 생깁니다.

설치 도중 하는 일
 - 이 폴더 안에 파이썬 환경(runtime)과 음성 모델(backend\models)을 설치합니다.
 - AI 대화 엔진 Ollama 가 없으면 공식 설치 파일을 받아 설치하고, AI 모델 qwen3:8b (약 5 GB)를 받습니다.
 - Ollama 와 AI 모델은 윈도우 사용자 폴더에 저장됩니다 (이 폴더 밖).

AI 엔진 고르기
 - 설치 중에 "AI 엔진을 골라 주세요" 가 나옵니다.
     1) 로컬 AI: 무료, 인터넷 없이 동작. Ollama + qwen3:8b (약 5 GB). NVIDIA 그래픽카드 권장.
     2) Claude Code CLI: Claude 구독 계정으로 로그인
     3) Codex CLI: ChatGPT 구독 계정으로 로그인
     4) Gemini CLI: 구글 계정 로그인 (구글이 무료 개인 사용을 중단해서 유료 플랜이 아니면 안 될 수 있습니다)
 - 2~4번은 Node.js 22 이상이 필요하고(없으면 설치 여부를 물어봅니다), 로그인은 각 CLI 가 직접 진행합니다.
   이 프로그램은 계정 정보를 저장하거나 다루지 않습니다.
 - 2~4번은 본인의 구독 계정을 쓰므로 그 서비스의 사용량 한도가 적용됩니다.
 - 나중에 바꾸려면 프로그램의 오늘 > 설정 > AI 엔진 에서 바꿀 수 있습니다.
   (설치.bat -Engine local / claude / codex / gemini 로 다시 설치 단계를 실행할 수도 있습니다)

[사용]
 - 회화연습.exe 를 더블클릭하면 됩니다. (처음 켤 때 "AI 엔진 준비 중…" 이 15초~1분 걸립니다)
 - 프로그램을 닫으면 음성/AI 서버도 같이 꺼집니다.
 - 이 폴더를 다른 곳으로 옮기면 안 됩니다. 옮겼다면 설치.bat 을 다시 실행해 주세요.
 - 마이크: 윈도우 설정 > 개인 정보 > 마이크 에서 "데스크톱 앱이 마이크에 액세스하도록 허용" 을 켜 주세요.
 - 그래픽카드(NVIDIA)가 있으면 음성 인식이 빨라지고, 없으면 CPU 로 동작합니다.

[문제가 생기면]
 - 설치 실패: 설치.bat 을 다시 실행해 보세요. 끝난 단계는 건너뜁니다. 계속 실패하면 install.log 파일을 확인하세요.
 - "Ollama를 실행해 주세요": 시작 메뉴에서 Ollama 를 실행하세요.
 - 서버만 따로 켜기: backend\run_backend.bat (끄기: backend\stop_backend.bat)

[업데이트]
 - 이 폴더의 업데이트.bat 을 더블클릭하면 GitHub 에서 최신 버전을 확인해서 자동으로 업데이트합니다.
   최신이면 "최신 버전입니다" 라고 나옵니다.
 - 학습 기록, 설정, AI 엔진 선택, API 키는 그대로 남습니다. 바꾸기 전 파일은 backup 폴더에 보관되고,
   문제가 생기면 자동으로 이전 버전으로 되돌립니다.
 - 최신 버전 페이지: https://github.com/Whahan/hoehwa-practice/releases/latest

[제거]
 - 제거.bat 을 더블클릭하면 이 폴더 안의 설치물(runtime, 음성 모델, 로그)을 지웁니다.
   Ollama, AI 모델, 학습 기록은 지우지 않습니다.
