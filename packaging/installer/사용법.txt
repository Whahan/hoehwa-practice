회화 연습 (영어/일본어) - 설치와 사용법
==========================================

[설치]
setup.exe 로 설치했다면 더블클릭만 하면 됩니다. 질문 없이 진행 막대만 보이고, 끝나면 바로가기가 생기고 앱이 켜집니다.
(zip 파일로 받았다면 아래 "zip 으로 설치한 경우"를 보세요)

 - 인터넷이 필요합니다. 약 4~6 GB 를 내려받고 10~15분 걸립니다 (인터넷 속도에 따라).
 - 디스크 여유 공간: 설치하는 드라이브에 NVIDIA 그래픽카드가 있으면 14 GB, 없으면 10 GB 이상, 임시 폴더 드라이브에 3 GB 이상.
 - NVIDIA 그래픽카드가 없으면 GPU 전용 라이브러리(약 2 GB)는 설치하지 않습니다. 음성 인식은 CPU 로 동작합니다.
 - 관리자 권한 확인 창은 뜨지 않습니다. 설치 폴더 이름이 너무 길면(95자 초과) 짧은 폴더를 쓰세요.
 - 중간에 창을 닫거나 인터넷이 끊겨도 같은 setup.exe 를 다시 실행하면 이어서 합니다.
 - 실패하면 한 줄 원인과 install.log 위치가 나옵니다.

설치 도중 하는 일
 - 이 폴더 안에 파이썬 환경(runtime), 음성 모델(backend\models), OpenCode(backend\tools\opencode),
   자바(JRE, backend\tools), 문법 검사기 LanguageTool(backend\tools\languagetool)을 설치합니다.
 - 모든 다운로드는 공식 주소에서 받고 SHA256 으로 확인합니다.

zip 으로 설치한 경우 (설치.bat)
 1. 받은 zip 파일을 "모두 압축 풀기" 합니다. (zip 안에서 바로 실행하면 안 됩니다)
    폴더 이름이 너무 길면 안 됩니다. 예: C:\회화연습
 2. 풀린 폴더의 설치.bat 을 더블클릭합니다. 검은 창에서 단계별(1/11 ~ 11/11)로 자동 설치됩니다. 바로가기는 만들지 않습니다.

AI 연결 (한 번만)
 - 설치 중에는 로그인하지 않습니다. 앱에서 AI 대화·AI 레슨을 처음 쓸 때 [AI 연결하기]를 누르고,
   OpenCode 에서 로그인해 API 키를 복사해 붙여 넣으면 됩니다. AI 엔진은 OpenCode 의 무료 DeepSeek 하나입니다.
 - 연결하기 전에도 레슨, 받아쓰기, 발음 채점, 쉐도잉, 노래 외우기 등 AI 가 필요 없는 기능은 그대로 쓸 수 있습니다.
 - 키는 이 PC 의 OpenCode 에만 저장되고 이 앱은 키를 저장하거나 기록하지 않습니다.

[사용]
 - 바탕화면의 "회화 연습"(또는 회화연습.exe)을 더블클릭하면 됩니다. (처음 켤 때 "AI 엔진 준비 중…" 이 15초~1분 걸립니다)
 - 프로그램을 닫으면 음성/AI 서버도 같이 꺼집니다.
 - 이 폴더를 다른 곳으로 옮기면 안 됩니다. 옮겼다면 다시 설치해 주세요.
 - 마이크: 윈도우 설정 > 개인 정보 > 마이크 에서 "데스크톱 앱이 마이크에 액세스하도록 허용" 을 켜 주세요.

[문제가 생기면]
 - 설치 실패: 같은 setup.exe(zip 설치는 설치.bat)를 다시 실행해 보세요. 끝난 단계는 건너뜁니다. 계속 실패하면 install.log 를 확인하세요.
 - Windows 가 "PC 를 보호했습니다" 창을 띄우면 [추가 정보] 를 누른 뒤 [실행] 을 누르세요. 서명이 없는 새 프로그램이라 나오는 경고입니다.
 - AI 가 안 될 때: 앱의 [AI 연결하기]로 다시 연결해 보세요.
 - 서버만 따로 켜기: backend\run_backend.bat (끄기: backend\stop_backend.bat)

[업데이트]
 - 시작 메뉴의 "회화 연습 업데이트"(또는 이 폴더의 업데이트.bat)를 실행하면 GitHub 에서 최신 버전을 확인해서 자동으로 업데이트합니다.
   최신이면 "최신 버전입니다" 라고 나옵니다.
 - 학습 기록, 설정, API 키는 그대로 남습니다. 바꾸기 전 파일은 backup\<이전 버전> 폴더에 보관되고,
   문제가 생기면 자동으로 이전 버전으로 되돌립니다.
 - 앱 폴더가 커지지 않게 정리합니다: 백업은 직전 것 하나만 남기고, 내려받은 업데이트 파일과 임시 폴더는 바로 지우고,
   새 버전에 필요 없어진 음성 모델 파일도 지웁니다. 끝에 "업데이트 전 X GB → 후 Y GB" 로 보여 줍니다.
 - 최신 버전 페이지: https://github.com/Whahan/hoehwa-practice/releases/latest

[제거]
 - setup.exe 로 설치했다면 윈도우 설정 > 앱 에서 "회화 연습"을 제거하거나 시작 메뉴의 "회화 연습 제거"를 실행하세요.
 - zip 으로 설치했다면 제거.bat 을 더블클릭하면 이 폴더 안의 설치물(runtime, 음성 모델, 로그, OpenCode, 자바)을 지웁니다.
 - 어느 쪽이든 학습 기록(%APPDATA%\Godot\app_userdata\회화 연습)과 OpenCode 로그인은 지우지 않습니다.
