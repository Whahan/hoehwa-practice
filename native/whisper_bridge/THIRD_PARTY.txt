WhisperBridge - third party software and data (docs/v200_phone_design.md section 1.2)

The built library (libwhisper_bridge.android.arm64.so / whisper_bridge.windows.x86_64.dll) statically contains:

1. whisper.cpp v1.9.5 (commit d1be6fde11ac6e0407606b4e42fe72d34add8037) and its bundled ggml
   https://github.com/ggml-org/whisper.cpp
   License: MIT, Copyright (c) 2023-2026 The ggml authors

   Modified: whisper.cpp is used with one patch, patches/whisper_abort_in_sched.patch (applied by build.ps1 for the build only):
   the abort callback is also set on the ggml scheduler backends.

2. godot-cpp, tag godot-4.5-stable (commit e83fd0904c13356ed1d4c3d09f8bb9132bdc6b77)
   https://github.com/godotengine/godot-cpp
   License: MIT, Copyright (c) 2017-present Godot Engine contributors

Not part of the library, but used with it:

3. Whisper model weights (ggml-base.en-q5_1.bin, ggml-tiny.en-q5_1.bin): OpenAI Whisper, MIT License,
   converted to ggml format by the whisper.cpp project (https://huggingface.co/ggerganov/whisper.cpp).
   The models are downloaded by the app at run time; they are never stored in this repository.
