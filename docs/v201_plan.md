## 1. 다음 두 릴리스의 목표, 범위, 완료 기준

### 1.1 v2.0.1 — 폰 발음 채점 (P-ASR)

- **목표**: PC 연결 없이 갤럭시 S24 등 안드로이드 폰만으로 오프라인 영어 발음 채점을 제공한다. 1주차 따라 말하기와 5주차 문장 말하기에 닿기 전(**2.0.0 공개 후 4주 이내, 2026-12-17 상한**)에 폰 말하기를 자가 평가에서 자동 채점으로 전환한다.
- **넣을 것**:
  - 보관 중인 `P0`(폰 우선 `/stt`·`/score` 라우팅, `need_ph` 예외, 1회 PC 재시도)·`PA1`(`WhisperBridge` arm64 `.so` 및 Windows 시험 `.dll`)의 `main` 병합.
  - `PA2`(`ScoreCore` 채점 코어 + 파이썬 황금 일치), `PA3`(`ModelStore` 이어받기·SHA-256 검증·와이파이/공간 확인 + `models.json` + 설정 모델 카드), `PA4`(`LocalStt` 핸들러, 비동기 로드/언로드, 12초 타임아웃, 저사양 보호).
  - `PA5`(합성 1,000+ 클립 + 사용자 녹음 약 60클립 점수 보정 → `score_params.json`), `PA7`(비-Gradle APK 빌드 통합·16KB 정렬·`allowBackup=false` 검사·PC 내보내기 제외).
  - `PSA`(설정 모델 카드·`score_where` 라디오·`CapabilityPanel`), `PWA`(자가 평가 화면 모델 받기 진입·"폰 간이 채점" 표시·`need_ph` 연결·쉐도잉/노래 문구 갱신), `PZ`(2.0.1 문서 절).
  - GitHub 릴리스 `models-1`(`ggml-base.en-q5_1.bin` 약 60MB, `ggml-tiny.en-q5_1.bin` 약 32MB) 업로드 및 Hugging Face 미러 SHA-256 고정.
  - 2.0.0 후속 소규모 정리(4절 추천안: 1주차 소리 노트 TTS 연결, 원고 M3 3건, E4b 오류 제목).
- **뺄 것**:
  - 폰 AI 직접 연결 전체(2.0.2로 분리).
  - 일본어 음성 인식·채점, 음소 단위 교정·억양 그래프(모두 PC 전용 유지).
  - Gradle 커스텀 빌드, 안드로이드 권한 추가(기존 3개 유지), `project.godot`·서버(`backend/`)·동기화 스키마 변경.
  - `base.en-q8_0` 등 상위 모델(S24에서 `base.en-q5_1`이 1.9초로 이미 목표 충족. 보정 미달 시에만 재검토).
- **완료 기준(사용자 관점, 측정 가능)**:
  1. **설치·다운로드**: 2.0.0 APK 위 덮어쓰기 설치 후 코스 진도·복습 카드 유실 0건. 와이파이 확인 후 `base.en-q5_1`(약 60MB) 다운로드·중단 후 이어받기·SHA-256 검증·삭제 동작(실기 H2).
  2. **오프라인 채점·체감**: 비행기 모드에서 1~16주 코스 말하기·레슨·쉐도잉 채점이 동작하고 네트워크 요청 0건(실기 H5). 정상 발음 10문장과 의도적 오발음 10문장 비교 시 정상 문장은 대체로 70점 이상, 틀린 단어는 실패 표시, 납득하기 어려운 이상 점수 2건 이하(실기 H4).
  3. **보정 정확도(PA5 보류 30%)**: 단어 `ok` 일치율 합성 85% 이상·사용자 80% 이상, 최종 점수 MAE 10점 이하·p90 20점 이하, 유창성 MAE 15점 이하, 틀린 클립이 깨끗한 클립보다 낮은 쌍 95% 이상, 오발음 통과(70점+) 10% 이하·정상 탈락(70점 미만) 10% 이하.
  4. **성능·안정성(갤럭시 S24 실기 H3)**: 3~6초 문장 20회 채점 p50 3.0초 이하·p95 6.0초 이하(12초 중단), 첫 모델 로드 3초 이하, RAM 증가 600MB 이하, 60회 연속 채점 배터리 감소 4%p 이하(대조 대비)·온도 상승 6.0°C 이하, 비정상 종료 0회.
  5. **빌드·회귀**: APK 전체 100MB 이하(직전 대비 증가 15MB 이하), `arm64-v8a` 단독, 16KB 페이지 정렬(`zipalign -c -P 16 -v 4`) 및 `allowBackup=false` 통과, PC 내보내기 팩에 `whisper_bridge` 0건, 기존 v2.0.0·일본어·PC 회귀 시험 전부 0 failed, 공개 링크(`models-1`·APK) 실다운로드 SHA-256 일치.

### 1.2 v2.0.2 — 폰 AI 직접 연결 (P-AI)

- **목표**: PC 없이 폰에 본인 AI API 키를 한 번 입력해 영어 대화(`/chat`), 대화 중 교정(`/fix`), 대화 피드백(`/feedback`), 미션 AI 판정(`/missions/judge`), 한 줄 일기 교정(`/fix` private)을 직접 사용한다. 2.1.0(17주차 안내형 AI 대화) 도달 전(**2.0.0 공개 후 12주 이내, 실질 목표 2026-12 말**)에 공개한다.
- **넣을 것**:
  - `PI0`(C0): 사용자 키 환경변수 1회 호출로 OpenCode Zen 유료 엔드포인트·`json_object` 지원·`single_system` 필요성·Gemini 최신 모델 id 확정.
  - `PI1`(`AiSecrets` 기기 결합 암호화 파일, `AiPresets` 4종 — OpenCode Zen 유료·DeepSeek·Gemini·OpenRouter, `AiClient` HTTPS 전용·`max_redirects=0`·오류 분류, `AiJson`, `AiState`).
  - `PI2b`(`LocalAi`·`AiChatRules` `/chat`·`/fix` private), `PI2c`(`AiFeedbackRules` `/feedback`·`/missions/judge`) — `main`에 있는 `PI2a` 황금 파일과 대조.
  - `PI3`(설정 "AI 연결(이 폰)" 카드·시트, 프리셋별 개인정보 동의 시트, 마스킹·클립보드 자동 비움, 한계·지출 한도 안내).
  - `PSI`(설정 연결·`CapabilityPanel` 갱신), `PWI`(일기 폰 경로·폰용 동의 문구·무료 학습 업체 일기 기본 꺼짐, 미션 AI 모드 허용, 홈·`main.gd`·`backend.gd` 폰 문구/이동 연결), `PZ`(2.0.2 문서 절).
- **뺄 것**:
  - 2.1.0 수준 맞춤 AI 대화(`course` 필드·`level_check`·`help_ko` → 2.1.0 `PI-L`). 2.0.2에서는 기존 `legacy_stage` 기반 대화만 제공한다.
  - 일본어 AI 기능(`ja_ai_pc` 안내로 PC 전용 유지), AI 레슨·노래 AI·읽기 문맥 뜻풀이 AI.
  - Android Keystore 연동(선택 K-스파이크는 2.0.2 이후 별도 판단), 중계 서버·공용 키, PC 앱의 폰 키 저장, 서버·동기화 스키마 변경.
- **완료 기준(사용자 관점, 측정 가능)**:
  1. **실사용 동작(실기 H7)**: 프리셋 선택·개인정보 동의·키 저장 뒤 화면에는 마지막 4자(`••••xxxx`)만 표시된다. 와이파이에서 영어 대화·교정·피드백·미션 AI·한 줄 일기 교정 각 1회 정상 응답 및 "오늘 N번 요청" 횟수가 표시된다.
  2. **키 비노출·개인정보(실기 H8·H10 + 자동 시험)**: 앱 로그·동기화 파일(`SyncDoc`·PC `progress.json`·허브)·`Store.prefs`·오류 화면에 키 조각과 일기 원문 마커 0건. 키 파일은 앱 내부 저장소에 암호화 저장되며 평문 키 0건, `allowBackup=false`, 302 리다이렉트 시 타 호스트 전송 0건. 무료 학습 업체(Gemini 무료)는 일기 교정 기본 꺼짐 및 별도 동의 전 요청 0건.
  3. **오류·요금 보호(실기 H9)**: 비행기 모드·잘못된 키·한도 초과·서버 오류 시 지정 한국어 안내 출력, 크래시 0건, 자동 재시도 0회(`bad_format` 1회 제외), 일기 원문 `saved` 유지. 자동 모드에서 PC AI 오류 시 폰 유료 키로 자동 전환하지 않는다.
  4. **프롬프트 일치·회귀**: `make_ai_golden.py --check` 및 `make_ai_json_golden.py --check` 종료 코드 0, 황금 사례 전체(chat 40+, fix 30+, feedback 20+, judge 20+) 전송 메시지·결과·시도 횟수 100% 일치, PC·일본어·2.0.1 폰 채점 회귀 시험 전부 0 failed.

## 3. 위험 상위 5개와 대응

| 순위 | 위험 | 영향 | 구체적 대응 |

## 4. 2.0.0 후속 결정 2건 및 WORKLOG 사소 문제 분류

### 4.1 1주차 알파벳 글자 소리 노트 TTS 미연결 — **2.0.1 포함 추천(안전 범위 제한)**

- **현황**: `course_src/en/weeks/w001.json`의 `kind:"sound"` 노트 31건(알파벳 이름 `n0103~n0128` 26건, 짧은 모음 `n0129~n0133` 5건)에 앱 TTS 재생 연결이 없다.
- **판단**: 1주차 첫 목표가 알파벳 26자 이름과 짧은 모음 소리 구별이므로, 0부터 시작하는 사용자가 1주차를 공부할 때 소리가 안 나면 입문 효과가 크게 떨어진다. 2.1.0까지 미루면 이미 입문 4주를 지난 뒤다. 다만 표준 TTS(Kokoro·안드로이드 시스템 음성)는 고립된 짧은 모음 한 글자(`"a"`)를 글자 이름("에이")으로 잘못 읽는 한계가 있다.
- **추천안**: **2.0.1에 소규모 패치로 포함한다.**
  - 알파벳 26자(`n0103~n0128`): 노트 옆 [듣기] 버튼으로 글자 이름(발음샘플에서 자연스럽게 확인된 읽기 글, 캐나다 `zed` 포함)을 `Tts.speak`로 재생한다.
  - 짧은 모음 5개(`n0129~n0133`): 고립 모음 대신 각 노트에 명시된 **예시 단어 묶음**(`cat, bag, hat` 등)을 재생해 오발음을 방지한다.
  - 안전장치: 발음샘플 확인 결과 TTS 글자 이름이 부자연스럽거나 구현이 2.0.1 일정을 2일 이상 지연시킬 경우 예시 단어만 연결하거나 2.0.2로 이월한다.

### 4.2 가격 읽기 `$5.99` → `five ninety-nine` 유지 여부 — **유지 추천**

- **판단**: 캐나다·북미 매장 실생활에서는 `$5.99`를 대부분 `five ninety-nine`으로 말하며, `five dollars and ninety-nine cents`는 현장 듣기 대비에 덜 실용적이다. 또한 `numbers_en.py`, 11주차 원고(`w011.json`), 전수 가드(36,895문제 위반 0)가 이미 이 규칙으로 정합되어 있어 변경 시 재빌드·재검수 비용만 크다.
- **추천안**: **`five ninety-nine` 방식을 그대로 유지한다.** 초급자 혼동을 줄이기 위해 11주차 문형 설명(`grammar_ko`)에 "가게에서는 `dollars and cents`를 줄여 `five ninety-nine`처럼 말한다"는 한 줄 보충만 확인·추가한다.
